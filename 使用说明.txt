一、安装

1. 必须先把 ZIP 完整解压，不能直接在压缩包预览窗口中运行。
2. 保存图纸并关闭所有 AutoCAD 窗口；安装器检测到 CAD 正在运行时会拒绝更新，以免替换已加载的 DLL。
3. 可先双击“安装前检测CAD版本.bat”，它只检测、不安装。
4. 双击“一键安装插件.bat”，在管理员权限提示中选择“是”。
5. 出现“INSTALLATION AND VERIFICATION SUCCEEDED”后重新启动 AutoCAD。
6. 在 CAD 命令行输入 ZHDIMHELP；显示命令列表即表示加载成功。

同一安装包会自动选择运行时：
- AutoCAD 2019/2020：R23
- AutoCAD 2021/2022：R24

插件安装到实际 AutoCAD 安装目录：
<AutoCAD安装目录>\SmartRoadPlugins\SmartRoad.CadDimensionTools

安装器从 Autodesk 注册表读取 AcadLocation；AutoCAD 安装在 D 盘时，插件也安装到对应 D 盘目录。它只新增 SmartRoadPlugins 子目录，不覆盖 Autodesk 原有文件，并校验 DLL 哈希、程序集版本和自动加载注册值。

已经安装基础版或旧版时，不需要先卸载：直接按以上步骤运行最新版“一键安装插件.bat”即可覆盖升级。安装器会在最新版复制和注册验证成功后，将旧版的：
%APPDATA%\Autodesk\ApplicationPlugins\SmartRoad.CadDimensionTools.bundle
自动移动到：
%LOCALAPPDATA%\SEU-NiZongyu\SmartRoad\LegacyPluginBackups

这是可恢复的旧版备份，用于避免基础版和动态版同时加载、命令重复。升级不会删除学习模板、Excel、DWG 或 SmartRoad_Backups 图纸备份。

二、Excel 使用方式

Excel 不需要提前粘贴到 CAD，也不需要预先打开。
执行命令后，在文件选择窗口中直接选择电脑上的 .xlsx 或 .xls 明细表。插件只读 Excel，不会修改工作簿。

主表需包含：
A 列：序号
B 列：道路名称
C 列：起点地址（可空）
D 列：止点地址（可空）
E 列：车行道长(m)
F 列：车行道宽(m)

三、动态识别数量（v1.3.1 新功能）

插件不再假定每个 DWG 都有 260 张图：

1. 先识别当前 DWG 中的全部粘贴表格锚点，得到实际图框数 N。
2. 再读取 Excel 中全部有效道路数据 M 条；M 可以大于 N。
3. 对每个当前 CAD 图框读取道路名称，与 Excel 道路名称精确匹配。
4. 名称存在错别字时，使用该图框内实际读取的 JT-1-xx 图号与 Excel 序号校验补充。
5. 本次只使用匹配当前图框的 N 条数据，Excel 中其余道路自动忽略。
6. 当前每张图必须唯一对应一条 Excel 数据；有任何漏匹配或重复匹配时，正式修改会被阻止。

因此，当前文件有 5 张就匹配 5 组，有 120 张就匹配 120 组，有 260 张就匹配 260 组。不会因为 Excel 中有更多数据而多标，也不会按图框排列序号盲目套用。

四、学习前几个图的标注习惯

1. 在当前 DWG 的前 2—5 张图中，按期望方式正确标注道路长度和宽度。
2. 每张样本图最好同时有一条长度标注和一条宽度标注。
3. 运行预检时，插件会自动从完整样本取中位数，学习：
   宽度锚点比例、长/宽尺寸线偏移、文字位置、标注样式和图层。
4. 当前 DWG 没有样本时，自动复用本 Windows 用户此前保存的跨 DWG 模板。
5. 样本中的标注数字不会用于推算；道路名称、长度、宽度始终来自本次选择的 Excel。

可选手动命令：
ZHDIMLEARN：依次选择同一图框的一条正确长度标注和一条正确宽度标注，保存模板。
ZHDIMPROFILE：查看模板来源、保存时间、样式、图层和锚点比例。

模板位置：
%LOCALAPPDATA%\SEU-NiZongyu\SmartRoad\annotation-profile.json

五、推荐调用流程

第一步，只读预检：

1. 打开待处理 DWG。
2. 输入 ZHDIMAUTOEXCELCHECK。
3. 选择对应 Excel。
4. 核对命令行中的：当前图框数、Excel 候选数、已匹配 N/N、几何定位 N/N、有效学习样本数。

预检不修改 DWG，也不创建备份。

第二步，正式执行：

1. 输入 ZHDIMAUTOEXCEL。
2. 选择刚才预检的同一个 Excel。
3. 确认没有阻止执行的问题。
4. 输入 Y。

插件会保留已有标注的锚点和位置，只更新其显示文字；缺少的标注按学习习惯新建。Excel 宽度为“/”时，CAD 标注也显示“/”。

六、标注点规则

长度：识别左右道路内侧向下边线，取最下方两点。
宽度：在学习到的道路中部位置，对上下两条道路边线作垂直标注。

标注锚点来自 CAD 几何；Excel 仅提供道路名称、长度和宽度值。

七、强制备份保护

正式修改前，插件必须先创建当前内存状态的完整 DWG 备份：
原 DWG 所在目录\SmartRoad_Backups\原图名_before_ZHDIM_yyyyMMdd_HHmmss_fff.dwg

备份失败时立即终止，事务不会开始，DWG 不会修改。当前识别的全部 N 张图在一个事务中提交，执行后可输入 UNDO 整体撤销。插件不会覆盖、另存或删除原图及历史备份。

八、其他命令

ZHDIMAUTO260CHECK / ZHDIMAUTO260：仅使用随插件附带的本项目 1—260 备用数据。一般项目请优先使用 ZHDIMAUTOEXCELCHECK / ZHDIMAUTOEXCEL。
ZHDIMBACKUP：手动创建当前图纸备份。
ZHDIMHELP：显示全部命令。
ZHDIMABOUT：显示版本、开发者和版权。

九、常见问题

1. 未知命令：关闭所有 AutoCAD 后重新运行安装程序，再启动 CAD。
   最新安装器会同时注册全部 ZHDIM 命令的按需加载映射；安装后必须彻底退出并重新启动 AutoCAD，不能只关闭当前 DWG。
   请打开解压目录中的 Install-Result.txt，第一行必须是 SUCCESS，版本必须是 1.3.1.0。
   如果 DLL 已是 v1.3.1，但旧安装包缺少命令映射，可关闭 AutoCAD 后双击“修复未知命令.bat”；看到 REPAIR AND VERIFICATION SUCCEEDED 后重启 CAD。
   若仍未知，在 CAD 命令行输入 DEMANDLOAD，将其设为 3，然后重新输入 ZHDIMHELP。
2. 手动 NETLOAD：
   2019/2020 选择 bundle\Contents\Windows\R23\SmartRoad.CadDimensionTools.R23.v1.3.1.dll
   2021/2022 选择 bundle\Contents\Windows\R24\SmartRoad.CadDimensionTools.R24.v1.3.1.dll
   如果 NETLOAD 后 ZHDIMHELP 可用，说明 DLL 正常、原问题是自动加载注册；重新运行最新版安装器即可修复。
   如果 NETLOAD 本身报错，请记录完整报错；常见原因是 AutoCAD LT、使用了错误 R23/R24 DLL、文件仍被 Windows 阻止，或单位安全策略禁止加载托管 DLL。
3. 已匹配不是 N/N：不要执行，检查 CAD 道路名称、JT-1-xx 图号以及 Excel 对应行。
4. 几何定位不是 N/N：不要执行，先检查该图道路上下边线及左右内侧向下边线是否与样本版式一致。
5. CAD 中原有粘贴表格可以保留，插件不会修改它。
